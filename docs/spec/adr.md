# ADR

決めたこと 1 つを、背景、選ばなかった案、結論と一緒に残す記録。`docs/` と Slot には今の姿だけを書き、どう決めてきたかは ADR に残す。docv が形を決めるファイルの 1 つで、置き場所は Slot と同じ `docv/` の下。

---

## 1. 置き場所と書き方

- `dir.slot`（既定は `docv`）の下の `adr/` に、決定 1 つを 1 つの Markdown で置く。ファイル名は `<id>.md` で、`.md` を除いた名前が決定を指す id になる
- システムが使う項目（`group`、`date`、`supersedes`）は YAML front matter に書く。決定の中身は本文に書き、本文の h1 を題にする
- 状態（採用、却下など）は持たない。ADR に残すのは決めたことだけで、打ち消されたかどうかは、新しい決定の `supersedes` から指されているかでわかる。打ち消されていない決定が、今の決定
- 本文は、背景、決めたこと、結果、選ばなかった案の章で書く
- 決めた後は書き換えない。決定を変えるときは、新しい ADR を書き、その `supersedes` から過去の決定の id を指す（未来から過去を参照する）
- 過去の決定から新しい決定へのつながりは、docv が `supersedes` を逆にたどって組み立てる。過去の ADR には書き足さない
- 用語を変えても、過去の ADR は書き換えない。過去の ADR が今の用語で読めなくなることは許す。用語集の Slot には今の用語だけを書き、昔の用語との対応は残さない

---

## 2. YAML front matter の項目

| 項目         | 必須 | 中身                                                                                    |
| ------------ | ---- | --------------------------------------------------------------------------------------- |
| `group`      | 任意 | まとまりの名前。同じ `group` の決定を、HTML で 1 つの図にまとめる。省略すると「その他」 |
| `date`       | 必須 | 決めた日（YYYY-MM-DD）。決定を並べる順と、`supersedes` が過去を指しているかに使う       |
| `supersedes` | 任意 | 打ち消す過去の決定の id の配列                                                          |

```markdown
---
group: 言語
date: 2026-03-01
supersedes: [go]
---

# Rust で書く

## 決めたこと

CLI は Rust で書き、単一のバイナリにして配る。

## 選ばなかった案

| 案         | 選ばなかった理由 |
| ---------- | ---------------- |
| Zig で書く | 情報が少ない     |
```

## 4. HTML での見せ方

- `ADR.html` に、`group` ごとに h2 を置き、決定のつながりを、過去から未来へ左から右に箱と矢印で並べる。打ち消された決定の箱は、破線で薄く出す
- 箱の幅はそろえ、題は箱の中で折り返す。1 列に並びきらないときは、その列を横にスクロールする
- 箱は決定のカードで、クリックすると決定 1 つのページ（`ADR/<group>/<title>.html`）を開く。決定 1 つを 1 ページにする
- 決定のページには、題を h1 にし、本文を出す。本文の見出しは h2 から始まるように段を付け直す。id と日付は出さない
- ADR のページは JPG にしない。ADR は Markdown なので、GitHub でそのまま見られる
- 決定のページの下に、前後の決定をカードで出す。打ち消した過去の決定は ← を付けて左に、この決定を打ち消した新しい決定は → を付けて右に置く。新しい決定へのつながりは、生成するときに `supersedes` を逆にたどって組み立てる
- カーソルキーの ← と → で、前後の決定のページに移れる。前後に決定が複数あるときは、先頭のカードのページに移る

```
言語
+-----------+   +-------------+
| Go にする | → | Rust にする |
+-----------+   +-------------+
+--------------+
| React にする |
+--------------+
```
