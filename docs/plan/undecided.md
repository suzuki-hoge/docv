## HTML に全文検索を置くか

HTML には検索がなく、ページ内の検索か、Free ファイルのツリーを目で探す。検索を置くには、検索用の索引と JS を出力に含める必要がある。JPG では検索は使えない。

## 図のファイルがないとき、サービス仕様の部品を docv が図にするか

サービス仕様の部品と依存（`depends`）から、docv が SVG を描けば、図の道具がなくても全体が見える。配置を毎回同じにする規則が要る。
