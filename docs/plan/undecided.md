docv の設計のうち、まだ決まっていないこと。決まったら Slot か `docs/spec/` に書き、ここから消す。

## Slot ファイルからスキーマを参照させるか

YAML の Slot のスキーマは `docv slot schema <slot>` で出せる。`docv.yaml` と同じように、Slot ファイルの先頭に yaml-language-server の書式で URL を書けば、エディタで補完と検証を効かせられる見込みがある。YAML で書いたスキーマをエディタが読めるかは、確かめていない。決まっていないのは、docv slot gen がその行を書くかと、check をスキーマで確かめるか。今の check は Slot の型で確かめていて、スキーマと 2 か所で揃えている。

## HTML に全文検索を置くか

HTML には検索がなく、ページ内の検索か、Free ファイルのツリーを目で探す。検索を置くには、検索用の索引と JS を出力に含める必要がある。JPG では検索は使えない。

## 図のファイルがないとき、サービス仕様の部品を docv が図にするか

サービス仕様の部品と依存（`depends`）から、docv が SVG を描けば、図の道具がなくても全体が見える。配置を毎回同じにする規則が要る。
