# 書式

このリポジトリのドキュメントの書式。docv としてのルール（種類、frontmatter、書き換えと retire）は [spec/writing.md](../spec/writing.md) に従い、ここではそれ以外の書式を決める。

---

## 1. 文章

- 日本語で書く
- Markdown の太字（`**`）は使わない。強調したいときは、見出し・箇条書き・表で構造を分ける
- 金額は `$` を使わず、「3 ドル」のように書く。GitHub は `$` で挟まれた部分を数式として表示するため

---

## 2. 構成

- 冒頭の 1〜2 行で、そのファイルが決めることと、関連するファイルへのリンクを書く
- 章には番号を振り（`## 1. 〇〇`）、章の間は `---` で区切る
- docs/ の中のファイルへのリンクは、表示する文字を docs/ からのパスにする（例: [spec/kind.md](../spec/kind.md)）。ファイル名だけだと、どのディレクトリのファイルか分からないため

---

## 3. 作業用のファイル

- tmp/ は作業用。コミットせず、ほかのドキュメントからリンクしない
