# ドキュメントを 1 つのディレクトリに集め、画像を使うファイルの隣に置く

## 背景

`docv.yaml` の `dir` には、Free ファイル、Slot ファイル、HTML、JPG、インデックスの置き場所を別々に書いていた。プロジェクトが、既存のディレクトリに合わせて配置を決められるようにするためだった。ADR と PDR は、Slot ファイルと同じ `dir.slot` の下に置いていた。

画像の置き場所は決めていなかった。`dir.slot` の下には Slot のほかのファイルを置けない。そのため、Slot で使う図も Free ファイルのディレクトリへ置くことになる。ADR から、今の姿を書いた図を参照すると、図を直したときに過去の決定の中身まで変わる。

ドキュメントは、原則として AI Agent が書いて直す。人間が探しやすいように、文章と画像を別のディレクトリに分ける必要はない。

## 決めたこと

`dir` は、ドキュメントを置く `dir.document_root` と、build の出力先の `dir.output` の 2 つにする。その下の配置は docv が決める。

- `document_root` の下には、`free/`（Free ファイル）、`slot/`（Slot ファイル）、`adr/`、`pdr/` と、build が作るインデックスの `README.md` だけを置く
- `output` の下には、`html/` と `image/` を置く。JPG を作るかは `generate.image` で決める
- `output` は、`document_root` の中に置けない。AI Agent が `document_root` を読むと、HTML に写した同じ内容がほぼ倍入るため
- インデックスは、build のたびに作る。名前を `README.md` にし、GitHub で `document_root` を開くと表示されるようにする。手で直されないように、末尾に作った docv の版を書く。HTML のサイドバーの一番下にも版を出す
- `ignore` は `docv_exclude` に名前を変える。`.gitignore` と取り違えないため

画像は、使うファイルと同じディレクトリに、`{使うファイルの名前}_{画像の名前}.{拡張子}` の名前で置く。名前の順に並べると、画像が使うファイルの隣に来る。持ち主のない画像は、check の error にする。複数のページで使う画像は、主になるページの隣に置き、ほかのページからはそのパスを参照する。共通の画像のディレクトリは作らない。

ADR と PDR は、それぞれのディレクトリの中の画像だけを参照できる。外の画像と URL の画像は、check の error にする。決定がそれだけで完結し、ほかのドキュメントを直しても、過去の決定が変わらないようにするため。

## 結果

AI Agent は、設定を読まなくても、どこに何を置くかが分かる。dir どうしを重ねられないという決まりと検査はなくなる。画像の置き場所で迷わなくなり、持ち主をなくした画像は check で見つかる。

既存のディレクトリに合わせた配置はできなくなる。docv を入れたプロジェクトは、ファイルを移し、リンクを直す。互換性を壊すので、版を 2.0.0 にし、`docv update-guide` に移し方を書く。出力をコミットするプロジェクトでは、docv の版を上げるたびに、HTML のすべてのページとインデックスに差分が出る。

## 見直す条件

- 既存のディレクトリを移せないことを理由に、docv を入れるのをやめたプロジェクトが出たとき
- `docv_exclude` で決まった配置から外したファイルが、どのプロジェクトでも同じ形で増えたとき

## 選ばなかった案

| 案                                                     | 選ばなかった理由                                                              |
| ------------------------------------------------------ | ----------------------------------------------------------------------------- |
| 今のまま、`dir` でそれぞれの置き場所を選べるようにする | 画像の置き場所が決まらない。AI Agent が、設定から置き場所を読み解く手間も残る |
| `output` を `document_root` の中に置く                 | AI Agent が読む範囲に、同じ内容がほぼ倍入る                                   |
| 画像を共通のディレクトリにまとめる                     | どのファイルの画像かが名前から分からず、使われなくなった画像に気づけない      |
| Free ファイルの画像の名前は check しない               | 名前を変えたり消したりしたファイルの画像が、持ち主のないまま残る              |
