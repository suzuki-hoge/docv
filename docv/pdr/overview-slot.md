# サービス概要の Slot を足し、サービス仕様と分ける

## 背景

サービス仕様の Slot のミッションは「これの目的、利用者、解決すること、部品の構成」で、利用者にサービスそのものを説明することと、詳しい仕様を書くことの 2 つが入っていた。仕様が詳しく長くなるほど、これが何かを知りたいだけの利用者が、仕様の中から説明を探すことになる。

## 決めたこと

サービス概要の Slot（`service/overview.md`、md）を足す。サービス概要には、これが何で誰の何を解決し、何ができるかを、利用者に向けて書く。サービス仕様には、機能と部品の構成と、それぞれの詳しい振る舞いと決まりを書く。

サービス仕様のまとまりは、サービス概要、サービス仕様、利用マニュアル、インストール、用語集の順に並べる。

## 結果

利用者は、サービス概要だけを読めば、これが何かがわかる。サービス仕様は、説明を気にせず詳しく書ける。

## 選ばなかった案

| 案                                         | 選ばなかった理由                                                    |
| ------------------------------------------ | ------------------------------------------------------------------- |
| サービス仕様の冒頭に概要を書く決まりにする | md の Slot の中身の形は決めないので、概要を書いたかを確かめられない |
