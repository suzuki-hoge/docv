# リンクの表示文字の規則をやめる

## 背景

check は、管理対象のファイルへのリンクの表示文字を、`dir.free` からのリンク先のパスにすることを、常に求めていた（`link-text`）。ファイル名だけでは、どのディレクトリのファイルか分からないためだった。実際には、この規則に頼って読む場面がなかった。md の Slot や ADR にも Free ファイルと同じ検査をかけるなら、この規則もそこへ広げることになる。

## 決めたこと

`link-text` をなくす。リンクの表示文字は、書く人が決める。

## 結果

リンクの表示文字に、パスでない言葉を使える。表示文字からリンク先のディレクトリは分からなくなる。
