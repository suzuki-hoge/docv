# HTML のコードブロックに build のときに色を付ける

## 背景

HTML のコードブロックは色がなく、YAML のスキーマのページなどで、キーと値の見分けがつきにくかった。

## 決めたこと

フェンスのコードブロックに、言語に合わせて色を付ける。色付けには Rust のライブラリ syntect を使い、構文の定義とテーマごとバイナリに埋め込む。色は build のときに HTML の中に埋め込み、JS は使わない。テーマは syntect の既定のテーマにある InspiredGitHub。

## 結果

HTML と JPG のコードブロックに色が付く。バイナリは構文の定義とテーマの分だけ大きくなる。言語がないか、syntect が知らない言語のブロックには色が付かない。
