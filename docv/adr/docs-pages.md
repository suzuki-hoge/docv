# 原本も HTML のページにする

## 背景

HTML のプロジェクト詳細のツリーは、原本の元の Markdown のファイルにリンクしていた。HTML を見ている人は、原本を読むたびに GitHub かエディタに移ることになる。

## 決めたこと

原本を 1 つずつ HTML のページ（`プロジェクト詳細/<原本のパス>.html`）にし、ツリーの題からリンクする。Slot や原本の本文の中にある原本へのリンクも、そのページに向ける。原本のページは JPG にしない。

## 結果

HTML の中だけで、全体像から原本の詳細まで辿れる。ツリーにファイル名を出す理由がなくなるので、ファイル名は出さない。

## 選ばなかった案

| 案 | 選ばなかった理由 |
| --- | --- |
| 元の Markdown のファイルにリンクする | HTML を見ている人が、原本を読むたびに HTML の外に出る |
