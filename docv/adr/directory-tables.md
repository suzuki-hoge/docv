# ディレクトリのページを 1 段ずつの表に分ける

## 背景

ディレクトリのページは、すべてのパスを 1 つの表に並べ、深さを字下げで見せていた。深いパスと浅いパスが同じ表に混ざり、どのディレクトリの中身かが読み取りにくい。

## 決めたこと

1 つの表には 1 段だけを「名前 | 説明」で出し、入れ子は表を分けて出す。いちばん上の段の表を先に置き、下の段を持つディレクトリごとに、そのパスの h2 と 1 段の表を後ろに並べる。下の段を持つディレクトリの名前は、その表へのページ内リンクにする。名前の列の幅は、表どうしで揃える。表の名前はコードの書式にし、h2 のパスはコードの書式にしない。パスから GitHub へのリンクは付けない。

## 結果

表を見れば、1 つのディレクトリの直下に何があるかが分かる。入れ子を折りたたまないので、JPG にもすべての表が写る。深い入れ子は、ページ内リンクで下の表へ移って読む。

## 選ばなかった案

| 案                                       | 選ばなかった理由                                                                                                 |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| `pre` のツリーのテキストにする           | 長い説明を、画面でははみ出させ、横にスクロールできない JPG では折り返すことになり、画面と JPG で見え方が分かれる |
| 入れ子を折りたたみ（`details`）で見せる  | 画像にしたとき、閉じた中身が写らない                                                                             |
| 1 つの表に全段を並べ、深さで字下げをする | どのディレクトリの中身かが読み取りにくい                                                                         |
