# Rust で書く

## 決めたこと

CLI は Rust で書き、単一のバイナリにして配る。

## 選ばなかった案

| 案        | 選ばなかった理由                                                                                         |
| --------- | -------------------------------------------------------------------------------------------------------- |
| Go で書く | GitHub Actions で各プラットフォーム向けにビルドするなら、Go のクロスコンパイルの手軽さは決め手にならない |
