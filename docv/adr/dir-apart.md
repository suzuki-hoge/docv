# dir の 4 つのディレクトリを互いに離し、HTML の既定を output/docv/html にする

## 背景

`dir.html` の既定の `docv/build` は、`dir.slots` の既定の `docv` の中にあった。Slot のディレクトリを読むときに、出力の HTML と JPG を除く必要があった。`dir.free` の中に `dir.slots` を書くなど、ほかの組み合わせでも、同じファイルを 2 つの役割で読むことになる。項目の名前は、`dir.free` などが単数で、`dir.slots` だけが複数だった。

## 決めたこと

- `dir.slots` を `dir.slot` にする
- `dir.html` の既定を `output/docv/html` にする。`dir.image` は今までどおり既定を持たず、書いたときだけ JPG を作る
- `dir.free`、`dir.slot`、`dir.html`、`dir.image`（書いたとき）は、どの 2 つも同じディレクトリにできず、一方が他方を含むこともできない。`docv.yaml` を読むときに確かめ、違反していれば、check、fix、build などは何もせずに終わる

## 結果

1 つのファイルは、Free ファイル、Slot ファイル、出力のどれか 1 つにしかならない。Slot のディレクトリを読むときに、出力を除く必要がない。

## 選ばなかった案

| 案                                           | 選ばなかった理由                                             |
| -------------------------------------------- | ------------------------------------------------------------ |
| 重なりを許し、読むときに出力を除き続ける     | 組み合わせごとに、どちらの役割で読むかを決め続けることになる |
| `dir.image` にも既定を置き、JPG を既定で作る | 既定の設定のままでは、Chrome のないマシンで build できない   |
