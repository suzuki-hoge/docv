# Slot のまとまりの名前を、サービスとシステムにする

## 背景

Slot のまとまりの名前は「サービス仕様」と「システム仕様」で、まとまりの中の Slot にも、同じ名前の「サービス仕様」と「システム仕様」があった。Doc ガイドの雛形で「仕様」はサービス仕様とシステム仕様の 2 つの Slot を指すと決めたが、同じ言葉がまとまりも指していた。HTML のパスも `サービス仕様/サービス仕様.html` になり、どちらがまとまりかが読み取りにくかった。

## 決めたこと

まとまりの名前を「サービス」と「システム」にする。開発者向けガイドと運用は変えない。Slot ファイルを置くディレクトリ（`service/`、`system/`）も変えない。

## 結果

「サービス仕様」「システム仕様」は、Slot だけを指す。HTML のプロジェクト概要の見出しと、HTML と JPG のパスのまとまりの部分が変わる（`サービス/利用マニュアル.html`、`システム/DB 仕様書.html`）。出力の JPG に、README などからリンクしているプロジェクトは、リンクを直す。

## 選ばなかった案

| 案                                        | 選ばなかった理由                                   |
| ----------------------------------------- | -------------------------------------------------- |
| まとまりの名前を変えない                  | 同じ言葉が、まとまりと Slot の両方を指し続ける     |
| Slot の名前を「サービスの仕様」などにする | Doc ガイドの雛形で決めた言葉と、ミッションが変わる |
