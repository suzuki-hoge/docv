# デプロイとリリースを別の md の Slot にする

## 背景

運用のまとまりに、デプロイとリリースを 1 つにした YAML の Slot（手順の形）を置いていた。

## 決めたこと

環境に反映すること（デプロイ）と、版を決めて利用者に届けること（リリース）を、別の Slot（`operation/deploy.md` と `operation/release.md`）にする。どちらも md にする。

## 結果

どちらかしかないプロジェクトは、ある方の Slot だけを置ける。環境ごとの違い、承認、切り戻しなど、番号付きの手順に収まらないことも書ける。

## 選ばなかった案

| 案 | 選ばなかった理由 |
| --- | --- |
| 1 つの Slot のまま、手順の形で書く | 答える問いが 2 つあり、サーバーを持たない CLI のように片方しかないプロジェクトでは、Slot の名前と中身がずれる |
| 分けて、どちらも手順の YAML にする | デプロイとリリースは、手順のほかに書くこと（環境ごとの違い、切り戻し）が多く、`body` に寄せることになる |
