# ファイルが扱うことをミッションと呼び、読むと何が分かるかで書く

## 背景

Slot が扱うことを「答える問い」と呼び、Free ファイルの `mission` も「このファイルが答えること」と説明していた。ミッションの文も「〜は何か」「どう〜か」の疑問の形で書いていた。ドキュメントを開くのは、いつも疑問から始まるとは限らない。知りたいことがあるときに、どのファイルを読めばよいかが分かれば足りる。

## 決めたこと

Slot と Free ファイルが扱うことを、どちらも「ミッション」と呼ぶ。Slot のミッションは docv が決め、Free ファイルのミッションは YAML front matter の `mission` に書く。ミッションは、そのファイルを読むと何が分かるかを 1 文で書き、疑問の形にしない。

## 結果

Slot と Free ファイルの違いは、ミッションと形を誰が決めるかの 1 点で説明できる。「〇〇を知りたければこのファイル」と、ミッションから読むファイルを選べる。

## 選ばなかった案

| 案                    | 選ばなかった理由                                             |
| --------------------- | ------------------------------------------------------------ |
| 「問い」のまま残す    | 疑問を軸にドキュメントを管理しているように読める             |
| scope と呼ぶ          | 範囲の境界を指す語で、読むと何が分かるかが伝わらない         |
| subject、topic と呼ぶ | 「〜について」のような、何が分かるかの決まらない書き方を招く |
