# check の設定を太字、斜体、`$`、textlint の 4 つにする

## 背景

`lint` には、タグごとのルール、過去の言い回しの語の足し引き、8 つの書式の規則があり、`overrides` でパスごとに道具を外せた。設定が多く、何が効いているかを追いにくかった。

## 決めたこと

- `lint` は `bold`、`italic`、`dollar`（`allow` か `deny`）と `textlint`（`enable` か `disable`）だけにする
- 章番号（h2 のどれかが章番号で始まるファイルだけ）と、リンクの表示文字は、設定によらず常に確かめる
- タグごとのルール、過去の言い回しと終わったタスクの検査、HTML タグと画像の代替テキストと章の区切りの規則、`overrides` はなくす

## 結果

設定は 4 つの切り替えで済み、ほかの検査はどのプロジェクトでも同じになる。`mission` は、すべての Free ファイルで必須になる。章の区切りを見やすくしたいときは、HTML の CSS で調整する。

## 選ばなかった案

| 案                                   | 選ばなかった理由                               |
| ------------------------------------ | ---------------------------------------------- |
| タグごとにルールを付けられるまま残す | タグごとに制御する場面がなく、全体で同じでよい |
| 章番号を設定で必須にする             | 章番号を使わないファイルにまで強いることになる |
