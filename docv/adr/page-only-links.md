# HTML のリンクはページにだけ張る

## 背景

HTML は、Free ファイルにはそのページへリンクしていた。Slot ファイル、ADR、コードなどのほかのファイルには、`docv.yaml` の `repository.url` があれば GitHub に、なければ元のファイルにリンクしていた。HTML は clone したリポジトリで見るので、file:// で見ている人が GitHub へ移ったり、元の Markdown や YAML を開いたりすることになる。

## 決めたこと

リンクは、Free ファイル、Slot ファイル、ADR のページにだけ、出力先の中の相対パスで張る。ほかのファイル（コード、管理外のファイルなど）へのリンクは、文字だけを出す。`repository` の設定はなくす。例外は 2 つで、画像は元のファイルを相対パスで読み、API 仕様書と DB 仕様書の `ref` の先へは `index.html` のカードから相対パスでリンクする。

## 結果

file:// で開いても、ホスティングしても、HTML の中だけで辿れる。コードなどは、HTML からではなくエディタで開く。

## 選ばなかった案

| 案                                                         | 選ばなかった理由                                                                                    |
| ---------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `repository.url` を残し、ページのないファイルを GitHub へ  | clone したリポジトリで見るので、GitHub を辿る必要がない。非公開のリポジトリやオフラインでは開けない |
| ページのないファイルも、元のファイルに相対パスでリンクする | コードや管理外のファイルは、エディタで開けばよい                                                    |
