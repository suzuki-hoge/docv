# Slot のディレクトリの Markdown も整形する

## 背景

md の Slot と ADR は管理対象に入らず、docv fix の整形と textlint がかからなかった。表の縦の揃えは書いた人のエディタで決まり、エディタによって全角の文字の幅の数え方が違うため、直すたびに差分が出ていた。

## 決めたこと

`slots.dir` の中の Markdown（md の Slot と ADR）にも、管理対象のファイルと同じく、整形と textlint をかける。原本のルール（YAML front matter、書式の規則など）はかけない。表は、全角の文字を 2、それ以外の文字を 1 と数えて揃え、`docv fix` の結果を正とする。

## 結果

docv fix が md の Slot と ADR の表を揃える。`format.enabled` が true なら、揃っていない表を check が format-diff で出す。エディタで揃えた表は、fix で揃え直される。

## 選ばなかった案

| 案                              | 選ばなかった理由                                                                         |
| ------------------------------- | ---------------------------------------------------------------------------------------- |
| `docs` に `docv/**/*.md` を足す | 原本のルールがかかり、md の Slot と ADR にも YAML front matter の mission を求めてしまう |
| 表の幅を文字の数で数える        | 全角の文字を含む表が、等幅のフォントで揃って見えない                                     |
