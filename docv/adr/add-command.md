# Slot のファイルは、パスではなく Slot の名前で作る

## 背景

`docv new <パス>` で、原本、Slot、ADR のファイルを、パスに応じたテンプレから作っていた。

## 決めたこと

`docv add <slot>` で、Slot のファイルだけを作る。パスは指定しない。YAML の Slot には項目のサンプルを書き、md の Slot は空のファイルを作る。YAML と md のどちらでも置ける Slot は、`api-yaml` と `api-md` のように名前で形を選ぶ。原本と ADR は、コマンドを使わずに書く。

## 結果

Slot のパスを覚えなくてよく、`docv add --list` で作れる Slot が分かる。原本と ADR のテンプレはなくなる。

## 選ばなかった案

| 案                            | 選ばなかった理由                                                                                    |
| ----------------------------- | --------------------------------------------------------------------------------------------------- |
| `docv new <パス>` を残す      | Slot のパスは docv が決めていて、選ぶ余地がない。パスを書かせると、間違えたときに直させるだけになる |
| md の Slot にもテンプレを書く | md の Slot は自由に書くもので、サンプルの中身は消すことになる                                       |
