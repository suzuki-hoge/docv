# 枠のファイルは、パスではなく枠の名前で作る

## 背景

`docv new <パス>` で、原本、枠、ADR のファイルを、パスに応じたテンプレから作っていた。

## 決めたこと

`docv add <slot>` で、枠のファイルだけを作る。パスは指定しない。yaml の枠には項目のサンプルを書き、md の枠は空のファイルを作る。yaml と md のどちらでも置ける枠は、`api-yaml` と `api-md` のように名前で形を選ぶ。原本と ADR は、コマンドを使わずに書く。

## 結果

枠のパスを覚えなくてよく、`docv add --list` で作れる枠が分かる。原本と ADR のテンプレはなくなる。

## 選ばなかった案

| 案 | 選ばなかった理由 |
| --- | --- |
| `docv new <パス>` を残す | 枠のパスは docv が決めていて、選ぶ余地がない。パスを書かせると、間違えたときに直させるだけになる |
| md の枠にもテンプレを書く | md の枠は自由に書くもので、サンプルの中身は消すことになる |
