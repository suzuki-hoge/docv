# 現在の設定を HTML のページで見せる

## 背景

`docv.yaml` に何を書けて、どれが効いているかは、スキーマか `docv init --print` を読まないと分からなかった。

## 決めたこと

HTML のサイドバーのいちばん下に「現在の設定」を置き、`docv.yaml` のすべての項目と今の値を 1 つの表で並べる。書いていない項目は既定の値で出す。選ぶ項目は候補を横に並べ、選んでいる候補に色を付ける。表の後に、textlint の検査項目と非検査項目を並べる。

## 結果

人間は、設定の全体と効いている値を、ブラウザを開けば一目で確かめられる。`docv desc` は CLI で読むものなので、このページには誘導しない。

## 選ばなかった案

| 案                                     | 選ばなかった理由                         |
| -------------------------------------- | ---------------------------------------- |
| `docv config show` で、CLI に表で出す  | 項目が多く、端末では見づらい             |
| 選ぶ項目をチェックボックスで縦に並べる | 行が長くなり、選んでいる候補が目立たない |
