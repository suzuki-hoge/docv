# Slot のカードを折り返して並べる

## 背景

`index.html` の Slot のカードは、まとまりごとに 1 行で並べていた。画面に収まらないカードは、横にスクロールして見る。まとまりの Slot が増えると、幅の狭い画面では後ろのカードが隠れる。

## 決めたこと

カードは横に並べ、画面の幅に収まらなければ折り返す。カードの幅は固定のままにする。

## 結果

どの幅の画面でも、すべてのカードが見える。Slot の多いまとまりは、縦に 2 行以上を使う。

## 選ばなかった案

| 案                               | 選ばなかった理由                                 |
| -------------------------------- | ------------------------------------------------ |
| 横のスクロールのままにする       | スクロールしないと、置いていない Slot が見えない |
| カードの幅を画面に合わせて縮める | 長い Slot の名前が折り返す                       |
