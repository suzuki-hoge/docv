# Doc ガイドの雛形は、開発の手順で docv fix と docv check にかける

## 背景

Doc ガイドの雛形（`assets/template/doc-guide.md`）は、利用者のプロジェクトで docv fix と docv check を通す必要がある。雛形は docv の管理対象の外にあり、このリポジトリの docv fix と docv check はかからない。

## 決めたこと

`make check-doc-guide` で、雛形を一時ディレクトリに書き出して docv fix し、変わったら雛形に書き戻し、docv check を通す。`make fix` も、途中でこれを実行する。

## 結果

雛形は、利用者の手元と同じ条件で整形と textlint を通った形で配られる。製品の設定は増えない。

## 選ばなかった案

| 案                                                   | 選ばなかった理由                                         |
| ---------------------------------------------------- | -------------------------------------------------------- |
| cargo test で、雛形が整形済みかだけを確かめる        | textlint をかけられず、直す手段も別に要る                |
| docv.yaml に、管理対象の外のファイルを足す項目を作る | このリポジトリのためだけに、利用者にも見える項目が増える |
