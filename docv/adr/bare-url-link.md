# 本文にそのまま書いた URL も、HTML でリンクにする

## 背景

HTML では、`[文字](URL)` と `<URL>` の形で書いたものだけをリンクにしていた。GitHub は、文の中にそのまま書いた URL もリンクにする。GitHub で読めばリンクなのに、HTML では文字だけになり、コピーして開くことになっていた。

## 決めたこと

build は、本文の文字の中の http:// と https:// で始まる URL をリンクにする。URL は、空白、`<`、`>`、ASCII でない文字の前で終わる。末尾の句読点と、対になっていない `)` は URL に含めない。英数字の直後から始まるものはリンクにしない。リンク、画像、コード、HTML で書いた `<a>` の中は変えない。

## 結果

書き方を変えずに、HTML から URL を開ける。日本語の文に続けて書いても、文は URL に入らない。ASCII でない文字を含む URL は、その文字の前までがリンクになるので、`[文字](URL)` で書く。

## 選ばなかった案

| 案                                                  | 選ばなかった理由                                            |
| --------------------------------------------------- | ----------------------------------------------------------- |
| GitHub と同じく、空白の前までを URL にする          | 日本語の文に続けて書くと、文が URL に入る                   |
| `www.` で始まるものもリンクにする                   | scheme がなく、http と https のどちらで開くかを決められない |
| check で、`[文字](URL)` か `<URL>` で書くよう求める | 書く手間が増える。GitHub では、そのままでリンクになる       |
