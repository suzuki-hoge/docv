# check の指摘の強さをなくし、すべて error にする

## 背景

check の指摘には error と warn があり、warn だけなら終了コードは 0 だった。warn になるのは、textlint の指摘と、ディレクトリの Slot に書いたパスがないときだけだった。このリポジトリでは warn も 0 件にしてからコミットしていて、warn を許す場面がなかった。

## 決めたこと

指摘の強さをなくし、すべてを error として出す。指摘が 1 件でもあれば、check は終了コード 1 で終わる。

## 結果

check の終了コードだけで、通ったかどうかが分かる。textlint で誤検知が出るルールは、強さを下げるのではなく、非検査項目に移して扱う。

## 選ばなかった案

| 案                                | 選ばなかった理由                       |
| --------------------------------- | -------------------------------------- |
| warn を残し、warn でも 1 で終える | 終了コードが同じなら、分ける意味がない |
