# 原本を Free ファイルと呼び変える

## 背景

`docs/` の Markdown を「原本」と呼んでいた。docv は `docs/` から `docv/` を作るわけではなく、「原本」という呼び方は、2 つのファイルの関係を誤って伝える。

## 決めたこと

`docv/` の YAML と md を Slot ファイル、`docs/` の md を Free ファイルと呼ぶ。2 つは、問いと形を docv が決めるか、プロジェクトが決めるかで分かれる。Slot と Free の日本語の呼び方は定めない。管理対象と管理外の呼び方は残す。用語を変えても、過去の ADR は書き換えない。

## 結果

Slot、spec、guideline、README、コードのコメントから「原本」がなくなる。過去の ADR には「原本」が残り、今の用語では読めないことがある。

## 選ばなかった案

| 案                            | 選ばなかった理由                                        |
| ----------------------------- | ------------------------------------------------------- |
| Topic ファイル                | Slot との対の関係が、名前から読み取れない               |
| Doc ファイル                  | Slot ファイルもドキュメントなので、区別の名前として弱い |
| Text ファイル                 | Slot の md と YAML もテキストなので、区別にならない     |
| 過去の ADR の用語も書き換える | ADR は決めた後は書き換えない                            |
