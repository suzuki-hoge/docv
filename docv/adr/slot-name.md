# 規格のファイルを Slot と呼ぶ

## 背景

どのプロジェクトにもある問いに、決まった形で答える規格のファイルを「枠」と呼んでいた。

## 決めたこと

「Slot」と呼ぶ。ドキュメント、CLI のメッセージとヘルプ、コードのコメントで揃える。

## 結果

`docv add <slot>`、`docv.yaml` の `slots.dir`、`docs/spec/slot.md` と呼び方が揃う。

## 選ばなかった案

| 案           | 選ばなかった理由             |
| ------------ | ---------------------------- |
| 「枠」のまま | 何を指すのか意味がわからない |
