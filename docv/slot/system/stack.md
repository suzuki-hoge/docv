# 技術スタック

## 言語

| 名前                               | 用途                           |
| ---------------------------------- | ------------------------------ |
| [Rust](https://www.rust-lang.org/) | CLI 本体。単一のバイナリにする |

## 埋め込むもの

| 名前                   | 用途                                                                                                                                          |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| dprint-plugin-markdown | Markdown の整形（docv fix）。Rust のライブラリとしてバイナリに埋め込む。Prettier と違って Node.js がいらず、docv の版で整形の結果が固定される |
| syntect                | HTML のコードブロックの色付け（docv build）。構文の定義とテーマごとバイナリに埋め込む                                                         |

## 実行時に使うもの

| 名前           | 用途                                                            |
| -------------- | --------------------------------------------------------------- |
| Node.js（npx） | textlint を使うときだけ要る                                     |
| textlint       | 日本語の文章の検査。docv の版ごとに版を固定し、npx で取ってくる |

## 配布

| 名前   | 用途                                                                                      |
| ------ | ----------------------------------------------------------------------------------------- |
| GitHub | ソースと、版のタグごとのスキーマを置く。利用者は `cargo install --git` でソースから入れる |
