# 環境構築

## 前提とされるもの

| 名前                                                 | 用途                          |
| ---------------------------------------------------- | ----------------------------- |
| [Rust](https://rustup.rs/)（2024 edition の stable） | ビルドとテスト                |
| Node.js                                              | make fix で textlint をかける |

## 手順

### ビルドして手元に入れる

```sh
make install
```

このリポジトリのドキュメントは docv 自身で管理している。コードかドキュメントを変えたら、開発コマンドの `make fix` で確かめる。
