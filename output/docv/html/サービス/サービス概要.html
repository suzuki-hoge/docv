サービス概要

docv はプロジェクトドキュメントのためのフレームワークである。

解決すること

AI Agent と開発すると、コードと一緒にドキュメントも高速に増える。docv は、そのときに起きる次の課題を解決する。

単一プロジェクトにおける課題

  • AI Agent の生成する詳細な情報を人間が把握しきれない
  • AI Agent がドキュメントを決まりなく書き足し、一瞬で肥大化させる

複数プロジェクトにおける課題

  • 乱立する大量のプロダクトそれぞれでドキュメントルールを定義するのが面倒
  • とにかくさっと概要を把握したいのに、閲覧方法が定まっておらずなにから見ればいいかすぐ判別できない

できること

  • 詳細は docv desc もしくは https://github.com/suzuki-hoge/docv/blob/main/assets/desc.md を参照 ( 内容は同じ )

しないこと

  • テンプレートやチェッカー・ビジュアライザなどは提供するが、具体的な執筆方式には関与しない
    • そのため、docv そのものには LLM を含まない
    • そのため、図や API 仕様書などの書式やツールを指定しない
