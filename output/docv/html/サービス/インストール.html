インストール

前提とされるもの

名前版何に使うか
Node.jstextlint を使うときだけ要る。docv check --no-textlint なら要らない
Google ChromeJPG を作るときだけ要る

手順

GitHub のソースから入れる（Rust が必要）

cargo install --git https://github.com/suzuki-hoge/docv

手元のソースから入れる（Rust が必要）

クローンしたリポジトリや、手を入れている作業中のソースから入れる。リポジトリのルートで実行する。

make install

~/.cargo/bin/docv に入る。ソースを変えたら、もう一度実行すると入れ直せる。
