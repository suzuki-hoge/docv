用語集

ファイルの種類

日本語英語意味
Slotどのプロジェクトにも要るドキュメントを書くファイル（Slot ファイル）。docv がミッションと形を決める。docv/ に <まとまり>/<ID>.<拡張子> の名前で置く。19 の Slot がある
Freeプロジェクトがミッションと形を決める Markdown のファイル（Free ファイル）。AI Agent が読み書きし、詳細を記録する。docv.yaml の dir.free のディレクトリ（既定は docs/）に置く
ADRArchitecture Decision Record。技術の決定 1 つを、背景、選ばなかった案と一緒に残す記録。docv/adr/ に 1 つの Markdown で置き、決めた後は書き換えない
PDRProduct Decision Record。プロダクトやサービスの決定 1 つを、見直す条件、選ばなかった案と一緒に残す記録。docv/pdr/ に 1 つの Markdown で置き、決めた後は書き換えない

決まりの種類

日本語英語意味
ルールRuledocv の仕組みが決める決まり。Slot と docv.yaml のスキーマ、YAML front matter の key、check が確かめることなど。利用側は変えられず、docv desc と docv slot schema で見る
ガイドラインGuideline利用側がドキュメントを書くときの方針。調整の余地があり、利用側が自由に直す。Slot の Doc ガイドに書き、docv slot gen doc-guide で雛形を作る
設定Configdocv.yaml で切り替えること。check のルールや textlint を使うか、出力を git で管理するかなど。docv init --print で見る

ファイルの分類

日本語英語意味
管理対象docv.yaml の dir.free のディレクトリの下の Markdown。YAML front matter に mission が要り、check の対象になる
管理外dir.free の外にあり、ignore にも当てはまらない Markdown。docv は中身を見ない

書き方

日本語英語意味
ミッションMissionそのファイルを読むと何が分かるか。Slot のミッションは docv が決め、Free ファイルのミッションは YAML front matter の mission に 1 文で書く。中身は、ミッションに収まることだけにする
タグTagsFree ファイルに付ける分類。1 つのファイルに任意の数を付けられ、タグにルールを付けられる
