docv/pdr/rules-only.md

AI Agent にはルールファイルを渡すところまでにする

背景

AI Agent がドキュメントを書くとき、docv のルールに沿わせる手段が要る。

決めたこと

docv はルールファイル（docv desc）を出すところまでにする。ルールに沿って直させる作業や CLAUDE.md への追記は、フレームワークの外で利用者が行う。

結果

docv は特定の AI Agent の仕組みに依存しない。

見直す条件

  • docv desc を読ませても AI Agent が Doc ガイドに沿わないことが続き、利用者が同じ hook や設定を書き写すようになったとき

選ばなかった案

案選ばなかった理由
Skill を提供し、docv init で CLAUDE.md と hook を設定する特定の AI Agent の仕組みに寄りすぎる。利用者の CLAUDE.md や hook に docv が書き込むことになる
