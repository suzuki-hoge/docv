docv/pdr/local-only.md

check と HTML の生成はローカルで完結させる

背景

docv は、ドキュメントを書く人が手元で確かめ、手元で読むための道具。CI や公開の仕組みは、プロジェクトごとに違う。

決めたこと

check と build は、手元で実行して完結させる。CI での実行と公開は、利用者が必要なら自分で組む。

結果

利用者は、docv だけで check と HTML の生成ができる。CI で動かすときは、docv のコマンドを呼ぶ手順を利用者が組む。

見直す条件

  • docv を入れたプロジェクトで、CI で check を実行する同じ手順を、それぞれが書き写しているのを見つけたとき

選ばなかった案

案選ばなかった理由
GitHub Actions で check を実行し、HTML を公開するローカルで完結するほうが使いやすい
