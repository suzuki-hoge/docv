開発コマンド

  • 変えたら整えて確かめる
  • Doc ガイドの雛形を整えて確かめる
  • 手元の docv を新しくする

変えたら整えて確かめる

コードかドキュメントを変えたら、コミットの前に実行する。指摘が 1 件でもあれば止まる。

make fix
  • コードを cargo fmt で整え、cargo clippy と cargo test を通す
  • make check-doc-guide で docv を install し、Doc ガイドの雛形を整えて確かめる。以降は、install した docv で実行する
  • このリポジトリのドキュメントを docv fix で整え、docv check を通す
  • docv build で、HTML を output/docv/html/ に、JPG を output/docv/image/ に、インデックスを docv-index.md に作り直す。どれもコミットする。GitHub で docv-index.md から JPG を辿れるようにし、clone してすぐ docv open で HTML を見られるようにするため

textlint を使うので Node.js が、JPG を作るので Chrome が要る。

Doc ガイドの雛形を整えて確かめる

docv を install してから、雛形（assets/template/doc-guide.md）を一時ディレクトリに書き出して docv fix する。雛形は管理対象の外にあるため。変わったら雛形に書き戻して install し直し、docv check を通す。make fix も、途中でこれを実行する。

make check-doc-guide

手元の docv を新しくする

make install
