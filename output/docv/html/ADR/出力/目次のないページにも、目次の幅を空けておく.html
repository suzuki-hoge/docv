docv/adr/outline-width.md

目次のないページにも、目次の幅を空けておく

背景

すべてのページの右に目次を置き、見出しのないページでは目次を出していなかった。本文は、左のサイドバーと右の目次の間の真ん中に置く。目次のあるページとないページを行き来すると、本文の位置が横にずれる。

決めたこと

すべてのページの右に、そのページの h2 と h3 の目次を置く。id のない見出しには、Free ファイルと同じ形の id を付ける。見出しのないページでは、目次の代わりに、同じ幅の空の枠を置く。

結果

どのページに移っても、本文の位置は変わらない。見出しのないページは、本文の右に何もない幅が残る。

選ばなかった案

案選ばなかった理由
見出しのないページにも、題だけの目次を置く移る先のない目次は、中身があるように見えてしまう
HTML を変えずに、CSS だけで右の幅を空ける目次のあるなしを CSS で見分けることになり、込み入る
