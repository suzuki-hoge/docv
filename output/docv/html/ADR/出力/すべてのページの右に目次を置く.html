docv/adr/outline-on-every-page.md

すべてのページの右に目次を置く

この決定は打ち消された。新しい決定は 目次のないページにも、目次の幅を空けておく

背景

右のサイドバーの目次は、Free ファイルのページにだけあった。Slot のページ、ADR のページ、index、プロジェクト詳細には目次がなく、ページによって読み方が変わる。YAML の Slot や ADR の見出しには id もなく、見出しへのリンクを張れない。

決めたこと

すべてのページの右に、そのページの h2 と h3 の目次を置く。id のない見出しには、Free ファイルと同じ形の id を付ける。見出しのないページでは、目次を出さない。

結果

どのページでも、目次から見出しへ移れる。どのページの見出しにも、ページ内リンクを張れる。

選ばなかった案

案選ばなかった理由
Free ファイルと Markdown の Slot にだけ置くYAML の Slot や ADR のページだけ、目次がないままになる
見出しのないページにも空の目次を置く移る先がないので、場所を取るだけになる

新しい決定 →

目次のないページにも、目次の幅を空けておく
