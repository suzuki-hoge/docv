TypeScript で書く

この決定は打ち消された。新しい決定は Rust で書く

背景

ドキュメントを検査する CLI を作る。文章の検査には textlint を使い、textlint は Node.js で動く。

決めたこと

CLI は TypeScript で書き、npm のパッケージとして配る。textlint は、同じ Node.js の中からライブラリとして呼ぶ。

結果

textlint を外のコマンドとして呼ばずに済む。利用者は、Node.js を入れておく必要がある。

選ばなかった案

案選ばなかった理由
Rust で書くtextlint を外のコマンドとして呼ぶことになり、Node.js との受け渡しが増える
