Rust で書く

背景

TypeScript で書くと、利用者は Node.js を入れておく必要がある。textlint を使わないプロジェクトでも、docv を動かすためだけに Node.js が要る。docv は多くのプロジェクトに入れて使うので、入れる手間を小さくしたい。

決めたこと

CLI は Rust で書き、単一のバイナリにして配る。

結果

利用者は、Node.js がなくても docv を使える。textlint を使うときだけ Node.js が要り、docv は textlint を外のコマンドとして呼ぶ。開発者は、Rust の環境を用意する。

選ばなかった案

案選ばなかった理由
TypeScript で書き続けるtextlint を使わないプロジェクトにも Node.js が要る
Go で書くGitHub Actions で各プラットフォーム向けにビルドするなら、Go のクロスコンパイルの手軽さは決め手にならない
