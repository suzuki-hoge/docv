docv/adr/adr.md

決めた経緯は ADR で記録する

背景

archive は、外した本文を移したものの集まりで、保守するドキュメントではなかった。何を比べて何を選んだかを読み返すには、本文より、決定ごとの記録のほうが向いている。

決めたこと

決定 1 つを 1 つの Markdown で docv/adr/ に置き、ファイル名を id にする。システムが使う項目（group、date、supersedes）は YAML front matter に書く。決定を変えるときは、新しい決定の supersedes から過去の決定を指す。HTML では、まとまりごとに決定のつながりを図で見せる。

結果

docv retire、archive のディレクトリ、YAML front matter の source はなくなる。docs/ には今の姿だけを書く。

選ばなかった案

案選ばなかった理由
archive を続ける外した本文がたまるだけで、決めた理由を探しにくい
ADR に状態（採用、却下など）を持たせるADR に残すのは決めたことだけ。打ち消されたかは、新しい決定からのつながりでわかる
YAML front matter に id を書くファイル名と二重になる

カーソルキーの ← と → でも移れる。
