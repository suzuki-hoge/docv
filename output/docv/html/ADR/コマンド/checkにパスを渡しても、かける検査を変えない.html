docv/adr/check-paths.md

check にパスを渡しても、かける検査を変えない

背景

docv check にパスを渡すと、Slot と ADR の検査を丸ごと飛ばしていた。YAML の Slot の形が壊れていても、ADR の supersedes の先がなくても、パスを渡すと error 0 件になっていた。

決めたこと

パスで絞るのは、確かめるファイルだけにする。かける検査は、パスを渡さないときと同じにする。Slot と ADR は、ファイルどうしのつながりも見るので、すべて読んでから、渡したパスの指摘だけを出す。

結果

1 つのファイルを直しながら、そのファイルだけを、全体と同じ基準で確かめられる。パスを渡しても、Slot と ADR はすべて読む。
