docv/adr/link-anchor.md

リンクのアンカーを check で確かめる

背景

check はリンク先のファイルがあるかだけを確かめ、# 以降のアンカーは確かめていなかった。見出しを書き換えると、そこを指すリンクが黙って切れていた。HTML の見出しには、GitHub と同じ形のアンカーを付けている。

決めたこと

Free ファイルのリンクのアンカーが、リンク先の Markdown の見出しにあるかを確かめ、なければ link-anchor を出す。アンカーは HTML と同じ規則で作り、同じ見出しが続けば -1、-2 を付ける。# だけのページ内リンクは、そのファイルの見出しと比べる。Markdown でないファイルへのリンクのアンカーは確かめない。

結果

見出しを書き換えたときに、切れたリンクを check で見つけられる。GitHub と HTML のどちらで読んでも、確かめたアンカーで飛べる。
