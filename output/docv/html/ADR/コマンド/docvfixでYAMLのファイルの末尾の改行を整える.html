docv/adr/fix-yaml-newline.md

docv fix で YAML のファイルの末尾の改行を整える

背景

docv fix は Markdown だけを整形していた。docv.yaml と YAML の Slot の末尾に改行がなくても、直す手段がなかった。

決めたこと

docv fix は、docv.yaml と YAML の Slot の末尾の改行を 1 つにする。中身は変えない。format.enabled が true なら、check も同じ箇所を format-diff として出す。

結果

docv が扱うファイルは、どれも末尾の改行が 1 つにそろう。

選ばなかった案

案選ばなかった理由
YAML の中身まで整形する書いた順やコメントを崩すおそれがある
