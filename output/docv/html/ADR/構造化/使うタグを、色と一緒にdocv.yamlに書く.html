docv/adr/tag-colors.md

使うタグを、色と一緒に docv.yaml に書く

背景

タグは任意の数を付けられ、docv.yaml の tags を書いたときだけ、使えるタグを限っていた。HTML のタグの色は、出てきた順に割り当てていて、ファイルを足すと色の変わることがあった。

決めたこと

分類は、YAML front matter の tags に任意の数を書くタグで行う。使うタグは、すべて docv.yaml の tags に、名前（name）と色（color）を書く。tags にないタグは、check が error にし、tags に足すよう案内する。

結果

タグの色はプロジェクトが決め、HTML のどのページでも同じになる。タグを使い始めるときに、docv.yaml を直す手間が増える。

選ばなかった案

案選ばなかった理由
色を書かないタグには、順に色を割り当てる決まりが 2 つになり、色が変わることがある

← 過去の決定

種類をやめ、任意の数を付けられるタグで分ける

カーソルキーの ← と → でも移れる。
