docv/adr/manual-md.md

利用マニュアルを md の Slot にする

背景

利用マニュアルは YAML の Slot で、ページの構成はコマンドの形（先頭のコマンドの表と、コマンドごとの見出し）で決まっていた。このリポジトリの利用マニュアルでは、コマンドの一覧と詳細に加えて、スキーマの一覧を章として並べたい。

決めたこと

利用マニュアルは md の Slot（service/manual.md）にする。YAML の利用マニュアルはなくす。docv add の名前は manual のままにする。

結果

利用マニュアルは、ほかの md の Slot と同じくそのまま HTML に出し、JPG にしない。テンプレとスキーマはなくなり、docv schema manual は md の Slot としてエラーにする。

選ばなかった案

案選ばなかった理由
YAML と md のどちらでも置ける利用マニュアルは md にしたので、Slot の名前は manual であるべき
