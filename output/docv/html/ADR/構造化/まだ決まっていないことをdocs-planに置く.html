docv/adr/plan-for-undecided.md

まだ決まっていないことを docs/plan に置く

背景

このリポジトリでは、まだ決まっていないことを docs/fixme/open.md に、やると決めたタスクを docs/plan/ に分けて置いていた。どちらも片付いたら消すもので、置き場所を 2 つに分ける理由はなかった。docs/fixme/ は管理対象で、HTML にも出ていた。

決めたこと

まだ決まっていないことも docs/plan/ に置き、docs/fixme/ と「未決」のタグをなくす。docs/plan/ と docs/tmp/ の中のファイルへは、ほかのファイルからリンクせず、言及しない。ディレクトリには、運用を説明するために言及してよい。

結果

正式なドキュメントには、決まったことだけが残る。決まっていないことは HTML に出ず、片付いたら消す。

選ばなかった案

案選ばなかった理由
docs/fixme/open.md を残す事実と予定を、同じ管理対象の中に混ぜることになる
