docv/adr/desc-as-service.md

docv desc はサービス仕様と同じ docv の概要を出す

この決定は打ち消された。新しい決定は docv のサービス仕様をページに分け、1 ページ目を docv desc と同じファイルにする

背景

docv desc は、原本の書き方と spec の 3 つを AI Agent 向けにまとめたルールファイルを出していた。同じことが 2 か所にあり、どう揃えるかが決まっていなかった。

決めたこと

docv desc は docv の概要を出し、docv のサービス仕様のページと同じ内容にする。元のファイルは assets/desc.md で、docv/service/service.md はそのシンボリックリンクにする。

結果

規格の詳細は desc に書き写さない。desc とサービス仕様を別々に揃える必要がなくなる。

選ばなかった案

案選ばなかった理由
desc に規格の詳細をまとめ続ける同じことが 2 か所にあり、揃え続ける必要がある

新しい決定 →

docv のサービス仕様をページに分け、1 ページ目を docv desc と同じファイルにする

カーソルキーの ← と → でも移れる。
