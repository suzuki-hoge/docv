docv/adr/textlint-fixed-rules.md

textlint のルールと値を docv が決める

背景

docv.yaml の lint.textlint は、プリセット、ルールごとのオプション、表記ゆれの辞書、持ち込みの設定ファイルを書けた。textlint の設定をそのまま映した形で、textlint の変更に引きずられる。docv のドキュメントは事実を並べるもので、目的は AI Agent が書く文章のぶれをなくすこと。

決めたこと

lint.textlint は enable か disable だけにする。使うルールとその値は、ja-technical-writing と ja-spacing のルールごとに docv が決め、docv の版ごとに固定する。使わないルールも、使わないと明示する。

結果

同じ docv なら、どのプロジェクトでも同じ基準で文章を確かめる。ルールの一覧は、HTML の現在の設定のページと spec で見られる。プロジェクトごとの調整はできない。

選ばなかった案

案選ばなかった理由
文章の流儀（スペース、文体、長さ）だけを項目にするぶれがなければよく、項目を持つ理由がない
jtf-style も使う翻訳の実務文書向けで、ja-spacing と食い違う
持ち込みの textlint の設定ファイルを残すtextlint の設定に準拠した使い方が残る
