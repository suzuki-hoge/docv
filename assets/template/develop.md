# 開発コマンド

| すること           | コマンド    |
| ------------------ | ----------- |
| テストを実行する   | `make test` |
| サーバーを起動する | `make run`  |

## テストを実行する

```sh
make test
```

| オプション    | 意味                             |
| ------------- | -------------------------------- |
| `NAME=<名前>` | 名前に当たるテストだけを実行する |

<details>
<summary>行われること</summary>

- コードを整える
- テストを実行する

</details>

## サーバーを起動する

```sh
make run
```

<details>
<summary>行われること</summary>

- DB を起動する
- API サーバーを起動し、`http://localhost:8080` で待つ

</details>
