# 環境変数

| キー              | 説明               | ローカル環境   | 運用環境             |
| ----------------- | ------------------ | -------------- | -------------------- |

| `PAYMENT_API_URL` | 決済サービスの API | `.env.example` | ECS のタスク定義     |
