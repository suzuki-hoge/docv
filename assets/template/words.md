# 用語集

## 注文

| 用語 | 英語    | 意味                                     |
| ---- | ------- | ---------------------------------------- |
| 注文 | Order   | 利用者が、カートの商品を買うと決めたもの |
| 確定 | Confirm | 決済が通り、注文を取り消せなくなること   |

## 決済

| 用語 | 英語    | 意味                                     |
| ---- | ------- | ---------------------------------------- |
| 決済 | Payment | 注文の代金を、決済サービスで受け取ること |
